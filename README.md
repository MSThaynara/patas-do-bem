# Patas do Bem - IFTM

Projeto de monitoramento e bem-estar animal do IFTM Campus Ituiutaba.

## Como utilizar (Manual do Usuário)
- Acesse o link do site: [COLOCAR LINK DO GITHUB PAGES AQUI]
- Para ver os cães, clique na aba "Cães".
- Você pode filtrar os animais pelos botões de categoria.

## Guia do Desenvolvedor
- O sistema utiliza **Supabase** para o banco de dados.
- O arquivo principal de configuração é o `database.js`.
- As tecnologias utilizadas são HTML, CSS e JavaScript puro.
